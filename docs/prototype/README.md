# Prototype UI TrustGive

## Papan 7 layar (seperti referensi desain)

Buka di browser:

```bash
cd docs/prototype
python3 -m http.server 8765
```

Lalu buka: **http://127.0.0.1:8765/trustgive-ui-board.html**

Atau buka file `trustgive-ui-board.html` langsung di browser (double-click).

### Isi layar

| # | Layar | Role | MVP / usulan |
|---|--------|------|----------------|
| 1 | Login | Semua | MVP (tanpa link daftar) |
| 2 | Dashboard donor | Donor | Usulan |
| 3 | Detail campaign | Donor | MVP (disederhanakan) |
| 4 | Form donasi (stepper) | Donor | MVP + usulan UI |
| 5 | Riwayat donasi | Donor | Usulan |
| 6 | Dashboard organizer | Organizer | Usulan |
| 7 | Buat campaign | Organizer | MVP |

Untuk lampiran skripsi: zoom browser ~90%, screenshot seluruh halaman (scroll), atau print to PDF.

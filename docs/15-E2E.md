# Pengujian E2E (Playwright)

Lokasi: `frontend/e2e/`. Konfigurasi: `frontend/playwright.config.ts`.

## Prasyarat

- **Hanya UI publik (`@public`):** cukup `npm run dev` (Playwright dapat menjalankannya otomatis).
- **Login & API (`@integration`):** backend `go run ./cmd/server`, Hardhat jika perlu donasi penuh; akun demo dari [10-AKSES-LOGIN.md](10-AKSES-LOGIN.md).

## Menjalankan

```bash
cd frontend
npm install
npx playwright install chromium

# Semua tes yang tidak di-skip (publik + integration jika env di-set)
npm run test:e2e

# Hanya halaman publik (cocok untuk CI tanpa database)
npm run test:e2e:public

# Dengan backend lokal + akun demo
export E2E_DONOR_EMAIL=donatur@demo.local
export E2E_DONOR_PASSWORD=demo12345
export E2E_EXPECT_BACKEND=1
npm run test:e2e
```

Dev server sudah berjalan di terminal lain:

```bash
PLAYWRIGHT_SKIP_WEBSERVER=1 npm run test:e2e:public
```

## Tag

| Tag | Cakupan |
|-----|---------|
| `@public` | Beranda, login form, daftar campaign (tanpa API wajib) |
| `@integration` | Login donatur, `/health/ready` via proxy Vite |

Alur donasi + ZK + chain **belum** diotomasi di Playwright (butuh Hardhat stabil dan waktu proof); uji manual / skrip backend tetap dipakai untuk sidang.

## CI

GitHub Actions menjalankan `npm run test:e2e:public` setelah build frontend (tanpa backend).

# Pengujian E2E (Playwright)

Lokasi: `frontend/e2e/`. Konfigurasi: `frontend/playwright.config.ts`. Manual penggunaan UI: [21-MANUAL-BOOK.md](21-MANUAL-BOOK.md).

## Prasyarat

- **Hanya UI publik (`@public`):** cukup `npm run dev` (Playwright dapat menjalankannya otomatis).
- **Login & API (`@integration`):** backend `go run ./cmd/server`, Hardhat jika perlu donasi penuh; akun demo dari [10-AKSES-LOGIN.md](10-AKSES-LOGIN.md).

## Menjalankan

```bash
cd frontend
npm install
npx playwright install chromium

# Semua tes yang tidak di-skip (publik + integration jika env di-set)
npm run test:e2e

# Hanya halaman publik (cocok untuk CI tanpa database)
npm run test:e2e:public

# Dengan backend lokal + akun demo
export E2E_DONOR_EMAIL=donatur@demo.local
export E2E_DONOR_PASSWORD=demo12345
export E2E_EXPECT_BACKEND=1
npm run test:e2e
```

Dev server **sudah** berjalan di terminal lain (`npm run dev`):

```bash
PLAYWRIGHT_SKIP_WEBSERVER=1 npm run test:e2e:public
```

Tanpa dev server, **jangan** set `PLAYWRIGHT_SKIP_WEBSERVER=1` — Playwright akan menjalankan `npm run dev` otomatis.

### DataTable (`e2e/datatable.spec.ts`)

```bash
# Backend :8080 + akun pengelola demo
export E2E_EXPECT_BACKEND=1
npm run test:e2e:datatable
```

Dengan `npm run dev` sudah aktif di terminal lain:

```bash
export E2E_EXPECT_BACKEND=1
PLAYWRIGHT_SKIP_WEBSERVER=1 npm run test:e2e:datatable
```

### Data demo scroll tabel (manual)

Jalankan dari root (setelah ada campaign pengelola):

```bash
psql "${DATABASE_URL:-postgres://postgres:postgres@localhost:5432/trustgive?sslmode=disable}" \
  -f backend/scripts/seed_datatable_scroll.sql
```

| Halaman | Login | Yang dicek |
|---------|-------|------------|
| `/campaigns?mine=1` | pengelola | Tabel campaign (≥7 baris untuk scroll; seed 8× "Demo scroll UI …") |
| `/campaigns/:id` → **Donasi masuk** / **Transparansi** | siapa saja | 8 donasi, scroll jika **>5** (default) |
| `/organizer/donations` | pengelola | Gabungan donasi; scroll jika **>7** |
| `/donor/donations` | donatur | Riwayat (seed 11 baris; scroll jika **>10**) |
| `/admin/reconciliation` | admin | Cuplikan archive (6 baris) |

## Tag

| Tag | Cakupan |
|-----|---------|
| `@public` | Beranda, login form, daftar campaign (tanpa API wajib) |
| `@integration` | Login donatur, `/health/ready` via proxy Vite |

Alur donasi + ZK + chain **belum** diotomasi di Playwright (butuh Hardhat stabil dan waktu proof); uji manual / skrip backend tetap dipakai untuk sidang.

## CI

GitHub Actions menjalankan `npm run test:e2e:public` setelah `npm run build`, dengan `vite preview` (bukan dev server) agar stabil di CI.
